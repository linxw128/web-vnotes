#### 列表嵌套

列表（有序或无序）可通过缩进来表示层级关系，常用于表达子项或从属关系。
- ‌**无序列表**‌：使用 `-`、`+` 或 `*` 开头，子项在父项前添加 ‌**4个空格**‌ 或 ‌**1个制表符**‌。
- ‌**有序列表**‌：使用 `数字.` 开头，子项同样通过缩进表示。
```
1. 一级项
    - 子项1
    - 子项2
2. 一级项
    1. 子项1
    2. 子项2
```
