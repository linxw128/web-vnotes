#### 服务端运行

服务端程序下载后运行

```shell
./mongod.exe --dbpath=..\data\mydb
```

> Using MongoDB:          7.0.5

#### 客户端运行

客户端下载后运行：

```shell
./mongosh
```

> Using Mongosh:          2.1.4
