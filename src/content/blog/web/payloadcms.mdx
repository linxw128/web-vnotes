#### 官网
https://payloadcms.com/docs/getting-started/installation


#### 安装
npx create-payload-app

#### 运行
开发模式使用
npm run dev
生产环境使用
npm run build
npm run start
默认地址是localhost:3000
首次创建一个邮箱，再用localhost:3000/admin登录
3000端口是next.js的默认端口
