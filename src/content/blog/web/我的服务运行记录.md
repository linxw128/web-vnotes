#### 报错：502 Bad Gateway
nginx有运行，但没有运行后台服务

#### 启动vnote-web
运行
```
cd /var/www/vnotes-web
nohup npm run dev &
```

#### 启动code-server 
运行命令
```
cd /root/codeserver
nohup code-server &
```

#### 查看监听确认服务正常运行
```
netstat -tunlp
```

#### 退出注意
https://blog.csdn.net/chen_soldier/article/details/83146413
使用nohup，如果不使用exit退出shell，容易导致在shell被异常退出时，nohup的进程也会被结束，所以在执行完成命令后，需使用exit进行退出
